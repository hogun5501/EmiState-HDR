Abstract

When a display or light in a room changes state, the walls and floor that receive its light change too. Revisiting observed emissive states from novel views requires one stored representation per state, yet no public indoor dataset with state-specific training views supports measuring how compactly an additional state can be stored.

We present EmiState-HDR, a synthetic high-dynamic-range dataset of four indoor scenes, 13 configurations and 26 state transitions, with disjoint training views per state, evaluation views shared by all states, intermediate-state ground truth with known state values, emissive-material masks, and a per-view linearity audit of the ground truth. With 3D Gaussian Splatting, keeping the same number of Gaussians from the same full target model under the same refinement, existing selection criteria span 5.06 dB in target-state PSNR. As a baseline for this protocol, EmiState-GS learns a per-Gaussian gate from the target observations and keeps exactly the specified number of Gaussians.

What the dataset provides

State-specific training views

Each transition has 80 base-state and 80 target-state training cameras that never overlap, as in real captures where each state is recorded separately.

Intermediate-state ground truth

States at α = 0.2, 0.5, 0.8 (TV: every 0.1) are rendered separately with known intensities, so the target and intermediate states can be scored at 40 shared evaluation views.

Unclipped HDR, audited

Renderer EXRs are released as saved. Every intermediate view is checked against the linear relation between the endpoints, and all flagged views are listed.

Emissive-material masks

Per-view masks of local emitters and light fixtures measure how much of a state change lies outside the emitter.

13 configurations

Target state of every configuration at one camera. Configurations of a scene change the content on the local emitter: a menu board, a picture frame, a sign or a TV screen.

The change spreads beyond the emitter

Even when only a TV screen turns on, 53.1% of the display-space image change lies outside the screen, so a target state cannot be reproduced by updating the emissive region alone.
